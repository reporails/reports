# Reporails reports: State of AI Instruction Quality

Companion datasets for the "State of AI Instruction Quality" reports. Each folder is one release, named by the quarter its data was collected (`YYYY-QN`), and documents its own corpus, instrument and methodology.

| Release | Data collected | Corpus | Report |
|---|---|---|---|
| [`2026-Q2/`](2026-Q2/) | April 2026 | 28,721 GitHub repositories with agent instruction files | [The State of AI Instruction Quality](https://medium.com/@cleverhoods/the-state-of-ai-instruction-quality-30k-repo-analysis-ce49c7667a57) |
| [`2026-Q3/`](2026-Q3/) | September 2026 | 10,000 high-star English GitHub repositories | The State of AI Instruction Quality, Q3 2026 (link added at publication) |

Releases are not directly comparable. The corpus and the measuring instrument both changed between Q2 and Q3, so a difference between two releases is not a trend. Each release's README states its sampling frame, instrument and known biases.

Every release publishes repository metadata and aggregate statistics only: no instruction file content, per-repository scores, calibration constants or embeddings.

This repository was previously `reporails/30k-corpus`; old links redirect here.
